# GitHub Pages static cast surface

Shipped beside the reader at https://logos52.github.io/tsumugu/.

Canonical authoring lives in `tsumugu-core/docs/companion/` (and the vault mirror
`llm-knowledge-base/public/tsumugu/`). Re-copy those trees into this folder when
portraits, voice lines, or profile HTML change, then push `main` so Pages redeploys.

Relative paths in the HTML assume this folder is the site root (`cast/`, `portraits/`,
`voice-samples/` next to `cast-profiles.html`).
